# Skills

A collection of reusable skills and workflows for Codex.

Each skill lives in its own directory and includes a `SKILL.md` file with the instructions Codex follows. A skill may also include a `README.md` with an overview and usage notes.

## Available Skills

| Skill | Description |
| --- | --- |
| [Cost-Aware Development](cost-aware-dev/) | Routes repository work through a risk-based workflow with focused tests and reviews. |

## Using a Skill

Use the skill by name when describing a repository task:

```text
$cost-aware-dev <task>
```

See the skill's `SKILL.md` for its complete instructions.
